# 我的收藏

- Provide a dedicated list page for a member's saved listings, opened from the favorites count and the favorites activity shortcut on the My tab.
- Load authenticated items from `/users/me/favorites` and show a two-column grid with image, price, title, neighborhood, and a sold status when relevant.
- Open each saved listing in the listing detail page.
- Keep loading, retryable error, signed-out, and useful empty states. The empty state should link back to browsing.
- Use the Soft Cute UI tokens and compact card layout from the shared design system.
