# 睦淘小程序设计系统

## 视觉基调

- Soft Cute UI：温和、亲近、轻量，适合邻里闲置交换场景。
- 页面底色使用暖奶油色 `#FFF7F1`；内容卡片以白色为主，强调色使用柔和珊瑚粉 `#FF8FA3` / `#FFB5A7`。
- 正文用深暖棕 `#5A4A48`，辅助文字用 `#806C6A` 或更深的暖灰，确保小字仍清楚可读。
- 使用系统中文字体和 `rpx` 布局。页面需适配窄屏、安全区和微信原生导航栏。

## 组件和交互

- 列表卡片采用圆角白底与浅色分隔线；可操作行使用稳定的按压反馈，不通过缩放造成布局偏移。
- 图标使用 CSS 几何图形或本地矢量资产，不使用 emoji 作为界面图标。
- 开关使用微信原生 `switch`，明确绑定偏好字段并提供保存失败反馈。
- 异步页面必须有加载、失败和重试状态；破坏性本地操作先确认，并说明影响范围。
- 位置、手机号等敏感能力仅在用户主动操作后请求授权。隐私开关的默认值和实际用途需清楚呈现。
- 动画保持简短克制，并尊重减少动态效果的系统设置。

## 小程序实现约定

- 使用原生 WXML、WXSS 和 JavaScript；接口请求走 `utils/request.js`，登录走 `utils/auth.js`。
- 用户偏好持久化到服务端；草稿、浏览记录等明确标注为本机数据。
- 主题支持跟随系统、浅色和深色；深色样式至少覆盖页面背景、卡片、分隔线和文字。
- 页面新增或重做时同步更新 `pages/[page-name].md`。
